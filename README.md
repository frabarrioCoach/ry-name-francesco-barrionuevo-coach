# Francesco Barrionuevo — Mental Coach

Sito web statico per la pratica di mental coaching di **Francesco Barrionuevo**.

## Cosa trovi sul sito

- Presentazione e percorso personale
- Incontro conoscitivo gratuito (~30 minuti)
- Testimonianze
- Contatti (WhatsApp, email, Instagram, prenotazione)

## Tecnologie

HTML, CSS e JavaScript — nessun framework, sito leggero e veloce su mobile.

## Sviluppo locale

Apri `index.html` nel browser.

## Pubblicazione

Sito pubblicato con **GitHub Pages** dalla branch `main`.
